# Work charters

> **Brief:** Work charters describe continuing responsibilities that can outlive
> one assignment or harness process. An instance should add only domains with a
> clear purpose and authority boundary.

## Root repository reconciliation

- **Purpose:** Reconcile collaborator commits with canonical records and
  publish one verified, force-free response.
- **Authority:** This repository only, under the writer lease and current
  authenticated Git transport.
- **Completion shape:** Continuing charter; each wake ends at one acknowledged
  hosted checkpoint.

## Assignment-bound agent management

- **Purpose:** Propose, launch, observe, reconcile, and archive bounded agent
  instances across supported harnesses.
- **Authority:** Exactly the dossier, worktree, paths, tools, credentials, and
  lifespan named by each assignment.
- **Completion shape:** The authority row is removed before the reconciler
  archives a completed or cancelled dossier.
