# Agent dossiers

> **Brief:** A dossier binds one assignment-bound agent instance to explicit
> context, authority, runtime identity, ledgers, and completion conditions
> without depending on a particular harness.

- `proposed/` contains designed but non-live assignments.
- `active/` contains dossiers with current authority rows in `active.md`.
- `inactive/` contains reconciled completed or cancelled dossiers.
- `RUNTIME-TEMPLATE.md` defines the minimum receipt.

Raw transcripts and runner logs remain ignored local state. Durable dossiers
contain only privacy-safe summaries and receipts.
