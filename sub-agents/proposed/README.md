# Proposed agent dossiers

> **Brief:** Proposed dossiers are design records only. They grant no process,
> path, credential, or publication authority.

Create `sub-agents/proposed/<agent-id>/` with:

- `brief.md` — assignment, context, allowed actions, exclusions, and gates;
- `launch-prompt.md` — the exact initial prompt supplied to the harness;
- `runtime.md` — a copy of `RUNTIME-TEMPLATE.md` with declared fields;
- `work-document.md` — conclusions and handoff;
- `modified-paths.md` — complete path ledger;
- `errors.md` — failures, retries, and blockers.

Activate only after all material choices are resolved and the destination
worktree is clean and exact.
